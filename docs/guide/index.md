# User guide

This is the user guide for the Python package `pySNOM`, which provides
readers and processing tools for Scanning Near-field Optical Microscopy
(SNOM) measurements, covering images, spectra, and interferograms.

Here we provide examples of how to use this package, along with an
explanation of the typical read-then-process workflow. For detailed
documentation of the functions and classes provided by this package, see the
[API reference](../api/index.md).
