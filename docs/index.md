# pySNOM documentation

Python tools for processing Scanning Near-field Optical Microscopy (SNOM)
measurements, including image, spectrum, and interferogram workflows.

pySNOM provides readers and processing objects for working with experimental
SNOM data in Python. Start with the guide if you are new to the package, or go
directly to the API reference for detailed class and method documentation.
